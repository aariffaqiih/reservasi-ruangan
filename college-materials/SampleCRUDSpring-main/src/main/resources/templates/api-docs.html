REST API Documentation

Base URL: http://localhost:8080/api

Format Response
{ "success": true, "message": "...", "data": { ... } }
200 OK — Berhasil
201 Created — Data dibuat
400 Bad Request — Input salah
404 Not Found — Tidak ada
Buku — /api/buku
MethodEndpointFungsi
GET/api/bukuSemua buku
GET/api/buku/{id}Buku by ID
GET/api/buku/tersediaBuku stok > 0
POST/api/bukuTambah buku
PUT/api/buku/{id}Update buku
DELETE/api/buku/{id}Hapus buku
Anggota — /api/anggota
MethodEndpointFungsi
GET/api/anggotaSemua anggota
GET/api/anggota/{id}Anggota by ID
POST/api/anggotaDaftarkan anggota
PUT/api/anggota/{id}Update anggota
DELETE/api/anggota/{id}Hapus anggota
Peminjaman — /api/peminjaman
MethodEndpointFungsi
GET/api/peminjamanSemua transaksi
GET/api/peminjaman/aktifStatus DIPINJAM
POST/api/peminjamanBuat peminjaman
PATCH/api/peminjaman/{id}/kembalikanProses pengembalian
DELETE/api/peminjaman/{id}Hapus record
Contoh curl
# GET semua buku
curl http://localhost:8080/api/buku

# POST buku baru
curl -X POST http://localhost:8080/api/buku \
  -H "Content-Type: application/json" \
  -d '{"judul":"Test","penulis":"Saya","isbn":"123","stok":5}'

# PATCH kembalikan buku id=1
curl -X PATCH http://localhost:8080/api/peminjaman/1/kembalikan
